# **App Name**: ViralFyre

## Core Features:

- Dynamic Trending Grid: A high-performance interface for rendering video thumbnails and titles fetched dynamically from the database.
- Firestore View Tracking: Utilizes Firestore's atomic increment functionality to record and update video view counts in real-time.
- AI Content Hook Generator: An AI-powered tool that uses metadata to generate viral-style catchy titles and summaries for each video document.
- Live Performance Analytics: A dashboard UI showing trending metrics based on real-time database queries from Firestore.
- Seamless Video Modal: An immersive overlay that serves the YouTube embed and triggers analytics events upon playback.
- Secure Admin Submission: Interface for adding new video links directly into the database collection with validation.

## Style Guidelines:

- Primary Color: Vibrant Heat Orange (#F07E29), chosen for its energetic and high-tempo 'trending' energy.
- Background Color: Deep Carbon (#161210), a desaturated variant of the primary hue providing a sophisticated dark mode backdrop.
- Accent Color: Deep Crimson (#B31922), an analogous hue used for calls to action and critical interactive highlights.
- Headlines: 'Space Grotesk', a geometric sans-serif that lends a futuristic and technical look. Body: 'Inter', selected for its supreme legibility in data-dense layouts.
- Outlined monochrome icons with slight glow effects when active to mimic neon-style heat.
- Bento-grid style card layout for the main feed to emphasize content density and hierarchy.
- Smooth micro-interactions such as progressive loading for the trending metrics and spring-based scales for thumbnail hovers.
